# CHANGELOG

## v1.0.0+1 - Initial Release (2025-01-25)

### 🎉 Initial Features
- **Automatic Jurisdiction Logging**: Track days spent in each country/jurisdiction
- **End-to-End Encrypted Storage**: Your travel history is encrypted on-device for privacy
- **Visual Timeline & Map View**: See your movements clearly across time and geography
- **Exportable as CSV**: Export data for visa applications, tax filings, or legal records
- **Decentralized Sync via Nostr**: Relay-friendly and serverless data sharing between devices
- **Offline-First Design**: Works without internet connection
- **Custom Country Settings**: Set personalized time limits and tracking preferences
- **Notification System**: Get alerts for important travel milestones
- **Privacy-Focused**: Built with Purplestack - identity-optional and sovereignty-respecting

### 🔧 Technical Details
- Built with Flutter for Android
- Powered by Nostr protocol for decentralized data sync
- Uses Purplebase framework for modular architecture
- SQLite local storage with encryption
- Supports ARM64 and other Android architectures

### 📱 Platforms
- Android (ARM64, ARMv7, x86_64)

This is the initial public release of Trottstr, forked and enhanced from mkstack with focus on travel tracking, privacy, and decentralization.
