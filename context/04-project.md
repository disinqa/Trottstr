# Project: Country Stay Tracker App

using the rules of this stack "purplestack" Build me an app for tracking how long the user stayed in any specific country throughout the year. Whenever the user is traveling across border, he opens the app and records which country he is now. The app tracks how long he has stayed in any specific country this calendar year. It knows how long someone can stay inside any country before you turn into a tax resident, and gives users notifications early when hes on track to overstay. Users can also set times in the future as planned for stay, and this is considered in when the user will run out of time, considering planned future days as "taken". Nostr login (signup generates a keypair and singin expects an nsec), local database of events, and an encrypted backup of all events in chosen relay.
